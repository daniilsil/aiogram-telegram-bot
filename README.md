# Telegram-бот «13 Сказка» на pyTelegramBotAPI

Интерактивный Telegram-бот для чтения и прослушивания сказок. Проект разработан на популярной библиотеке **pyTelegramBotAPI** (telebot).

## 🚀 Основной функционал
* **Интерактивное меню:** Удобная навигация по 13 уникальным сказкам с помощью inline-кнопок.
* **Мультимедийный контент:** Поддержка отправки текстовых версий сказок, картинок-обложек и аудиофайлов.

## 🛠 Стек технологий
* **Язык:** Python 3.10+
* **Библиотека:** pyTelegramBotAPI (telebot)

## 📦 Как запустить проект локально

1. Клонируйте репозиторий:
   ```bash
   git clone https://github.com
   ```
2. Установите зависимости:
   ```bash
   pip install -r requirements.txt
   ```
3. Вставьте ваш токен в переменную `API_TOKEN` (или `bot = telebot.TeleBot('ТОКЕН')`) внутри кода.
4. Запустите бота:
   ```bash
   python script2.py
   ```
